# sub2loc

작품별 인물·말투·용어와 줄거리 맥락을 다음 화까지 이어가는 **로컬 ASS 자막 번역기**입니다. 자막을 여러 개 올려 순서대로 번역하고 결과를 ZIP으로 내려받습니다.

## 실행

Python 3.10 이상이 필요합니다. 외부 Python 패키지 설치는 필요 없습니다.

```bash
python -m sub2loc
```

저장소 폴더에서 실행하고 **http://127.0.0.1:8765** 를 여세요. Windows는 `start.bat`을 실행해도 됩니다. `py` 명령이 없으면 Python 설치 후 위 명령을 사용하세요.

```bash
python -m sub2loc --port 8766 --data-dir ./my-data
```

## 사용 순서

1. 로컬 모델 서버에서 모델을 불러오고 API 서버를 켭니다.
2. 작품명과 번역 언어를 입력합니다. 같은 작품명은 기존 맥락을 이어받습니다. 시즌을 분리하려면 작품명에 시즌을 붙이세요.
3. 인물 관계, 말투, 고유명사 표기처럼 알고 있는 정보를 메모합니다.
4. ASS 파일을 올리고 **표시된 회차 순서를 확인**합니다. 숫자를 고려한 파일명 정렬로 시작하며 화살표로 바꿀 수 있습니다. 파일명만으로 회차를 확정하지 않습니다.
5. API 기본 주소와 **서버의 정확한 모델 ID**를 입력합니다. 기본 주소는 `/chat/completions` 앞까지이며, 예를 들어 서버가 그 형태로 제공한다면 `http://127.0.0.1:1234/v1`입니다. 실제 포트와 경로는 서버 설정을 따릅니다.
6. 번역 시작 → 완료 후 ZIP을 받습니다. `*.translated.ass`와 맥락 메모 `context.txt`가 들어 있습니다. 원본 파일은 수정하지 않습니다.

작품명만으로 외부 작품 정보를 검색하지 않습니다. **사용자 메모, ASS Name 필드, 대사, 이전 번역의 맥락**을 활용합니다. 화자가 비어 있는 자막에서는 인물 추론에 한계가 있으며, 확실하지 않은 정보는 추측하지 않도록 요청합니다. 맥락 메모도 모델이 생성하므로 잘못된 추론이 이어질 수 있습니다.

## API 호환성 / 12B 모델

- `POST {기본주소}/chat/completions`의 비스트리밍 텍스트 응답을 사용합니다. 요청 필드는 `model`, `messages`, `temperature`, `max_tokens`, `stream`입니다.
- `GET {기본주소}/models`는 선택 사항입니다. 목록 조회를 지원하지 않아도 모델 ID를 직접 입력할 수 있습니다.
- 모델은 프롬프트에 맞는 JSON을 출력해야 합니다. 서버의 JSON 모드나 function calling은 요구하지 않습니다.
- 기본값은 대사 12개, 최대 출력 4096토큰, 요청 제한 180초입니다. 요청마다 문자 수로도 묶음을 제한합니다. 작은 모델에서 형식 오류가 나면 묶음을 4–8개로 줄이세요. 서버의 컨텍스트 길이도 충분히 설정해야 합니다.
- HTTP/연결 오류 또는 JSON·ID·태그 검증 실패 시 묶음당 최대 3회 요청합니다. 3회 실패하면 완료된 묶음을 보존하고 중단합니다.
- **Bionic의 특정 버전/12B 모델에 직접 연결한 검증은 아직 하지 않았습니다.** 서버가 위 프로토콜을 제공해야 하며, 실제 API 주소와 모델 ID를 설정해야 합니다. 번역 품질과 인물 추론 정확도는 사용 모델에 따라 달라집니다.

## ASS 보존 범위

타임코드, 스타일, Dialogue의 Text 외 모든 필드, Comment, 헤더, 첨부 섹션, 줄바꿈 형식과 UTF-8 BOM 유무를 보존합니다. `{...}` 태그, `\N`, `\n`, `\h`, `\p` 드로잉은 보호 토큰으로 바꾸고 결과에서 **개수·순서·원문**을 검증합니다. ID 누락·중복·순서 변경, 빈 번역, 모델이 추가한 제어 태그는 거부합니다. 드로잉만 있는 행은 API에 보내지 않습니다.

태그의 바이트 값과 순서는 유지하지만, 언어 간 어순 차이로 스타일 적용 구간이 부자연스러울 수 있습니다. 가라오케 태그의 개별 음절과 번역 음절을 다시 동기화하지는 않습니다.

UTF-8/UTF-16(BOM)/CP932/CP949 입력을 선택할 수 있으며 출력은 같은 인코딩을 사용합니다. CP932에서 한글처럼 표현할 수 없는 문자가 나오면 오류로 중단하므로, 그런 경우 원본 사본을 UTF-8로 변환해 사용하세요. Events Format은 마지막 필드가 Text인 형식을 지원합니다.

## 중단·재개와 저장

완료된 묶음마다 로컬 체크포인트를 원자적으로 저장합니다. 같은 작품명·파일 내용·파일 순서·번역 설정으로 다시 시작하면 이어서 처리합니다. API 키 변경은 체크포인트를 무효화하지 않습니다. 이미 완료된 동일 작업을 다시 시작하면 저장된 결과를 반환합니다. **일부 파일만 빼거나 설정을 바꾸면 새 작업**으로 취급합니다.

한 업로드 작업이 전부 완료된 시점에 작품의 맥락을 확정합니다. 이후 새 회차를 별도로 올리면 이 맥락을 이어받습니다. 순서를 거슬러 이전 회차를 새로 번역하면 미래 맥락이 사용될 수 있으므로, 새 작품명으로 작업을 분리하세요. 새로 번역하고 싶을 때도 새 작품명을 사용하세요. 중단 시 진행 중인 HTTP 요청은 타임아웃 또는 응답까지 기다릴 수 있습니다.

기본 저장 위치는 사용자 홈의 `.sub2loc`입니다. `--data-dir` 또는 `SUB2LOC_DATA`로 바꿀 수 있습니다. 체크포인트에는 번역 대사, 출력 파일, 작품명과 맥락이 저장됩니다. API 키는 저장하지 않습니다. 화면 설정과 작품 메모는 이 브라우저의 localStorage에 저장됩니다. API 서버 주소와 모델 설정도 저장되지만, 키는 제외합니다.

자막·작품 메모·이전 맥락은 **설정한 API 서버**로 전송됩니다. 외부 주소를 입력하면 외부 서버로 전송되므로 주소를 확인하세요. UI 서버는 `127.0.0.1`에만 바인딩하고 Host/Origin을 확인합니다. API 키와 원문을 HTTP 로그에 출력하지 않습니다. 동시 번역은 한 작업만 지원합니다.

## 검증

```bash
python -m unittest discover -s tests -v
```

실제 모델 없이 동작하는 가짜 API를 통해 ASS 보존, ID/토큰 오류, 재시도, 작품 맥락 전달, 중단·재개, HTTP API와 ZIP 출력을 검증합니다. `examples/demo.ass`는 실행 확인용 창작 예문입니다.
